## The word

**Swoopervisor** — a supervisor who swoops in, drops chaos, and leaves.

## How it works

`main.py` writes the single word to `/output/entry.txt` — 12 characters,
no trailing newline — passing the gate (UTF-8 text of 1–30 characters,
not only whitespace). It validates the word against the gate before writing.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
